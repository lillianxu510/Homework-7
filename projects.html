A Brief Introduction

In my time studying Data Science, I have had the opportunity to work on several projects involving data analysis and visualization. It's always a pleasure learning more about topics I have never studied before, and turning them into clean visualizations and studies.

However, this field of study also allows me to use data in completely different ways other than graphs! I have learned how to work with database design and how certain algorithms work, showing how data can be used in a wide variety of ways. I love data!

Project 1: City Livability Dashboard

One of my projects involved creating an interactive dashboard to explore factors that contribute to the livability of different places in the United States.

The dashboard combined datasets of population, crime rate, walkability, and cost of living. Using Python, and other visualization tools like Plotly and Panel, I helped create visualizations that allowed users to compare different locations and explore relationships between important livability factors.

Project 2: Video Game Database

Another project focused on designing and implementing a relational database for mock video game information. The goal was to organize information about games, developers, and users in a structured format.

We used MySQL to design the database and Python's Flask to create a locally hosted website. We also implemented REST API endpoints to update information from the database. This was a great introduction with working with databases and web applications.

Project 3: MBTA Transportation Analysis

Another project was analyzing public transportation data from the Massachusetts Bay Transportation Authority (MBTA). The project focused on finding any patterns in delays at certain stations.

Using a selected dataset of stations from the MBTA, I created a dataframe to analyze the different delay times overall, using regression techniques and machine learning to find trends.
